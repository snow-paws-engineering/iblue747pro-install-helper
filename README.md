# i-Blue 747Pro 非公式インストール支援キット

Transystem i-Blue 747ProをWindows 11 x64で使うための、非公式の導入スクリプトと説明書です。
Transystem、LOCOSYS、Qstarz、Microsoftによる提供・承認・サポートを受けたものではありません。

**ドライバー本体（INF / CAT / CAB / SYS）を同梱・再配布しません。**
利用者自身が配布元の条件を確認し、ドライバーを取得してください。
このスクリプトはダウンロードやセキュリティ設定の変更を行いません。

## 対象

- Windows 11 x64（管理者権限が必要）
- ハードウェアID: USB\VID_0E8D&PID_3329（REV_0100を含む）
- ARM64版Windowsは対象外

同じ製品名でもIDが異なる場合、このキットでの適合性は確認していません。

## ドライバーを自分で取得する

2026-11-09に以下の配布サイトからCABを取得できることを確認しました。

- [配布案内（DigiTrading）](https://digitrading.nl/veelgestelde-vragen-faq.html)
- [確認したCABの配布先](https://digitrading.nl/store/image/data/qstarz/Win10-driver-Qstarz.cab)

これらは外部サイトです。将来の配布継続、利用条件、内容を保証しません。
リンクを掲載することは再配布許可を意味しません。
ダウンロードできない場合、無関係なドライバーサイトから代用品を取得しないでください。

1. 上記配布元の条件を確認してCABを取得する。
2. CABを展開する。エクスプローラーで開いて中のファイルをコピーするか、
   Windows標準の展開機能を使用する。
3. Install.cmdと同じ場所に driver フォルダーを作り、次の2ファイルを入れる。

~~~text
Install.cmd
README.md
driver/
  Locosys_x64.inf
  ls_gps_x64.cat
~~~

INFを編集しないでください。内容を変えると署名との整合性が失われます。

## 導入する

1. GitHubの「Code → Download ZIP」でこの支援キットを取得し、「すべて展開」する。
2. 上記手順で、自分で取得したドライバーを driver フォルダーに入れる。
3. GPSをUSBで接続し、電源を入れる。
4. Install.cmdをダブルクリックし、管理者確認で「はい」を選択する。
5. デバイスマネージャーの「ポート(COMとLPT)」で
   **LOCOSYS Technology GPS Receiver (COM番号)** が警告なしで表示されることを確認する。

管理者権限への昇格に伴い、Windows標準PowerShellを起動します。
実行ポリシーの変更やBypass指定は行いません。
組織のポリシーなどで実行できない場合、管理者に相談してください。
Windowsの警告・セキュリティ制限を迂回しないでください。

## 通信を確認する

GPS対応ソフトで、表示されたCOM番号を選びます。

| 項目 | 値 |
| --- | --- |
| 通信速度 | 115200bps |
| データビット | 8 |
| パリティ | なし |
| ストップビット | 1 |
| フロー制御 | なし |

COM番号はPCや接続ポートによって変わります。COM6固定ではありません。
他のソフトがポートを使用している場合は閉じてください。

NMEAデータのRMCが継続的に届くことを確認します。
RMCの状態 A は測位有効、V は未測位です。
未測位の場合は空の見える場所で待ちます。
保存済み走行ログの一括取り出しには、別途747Pro対応ソフトが必要です。
この支援キットは通信テストやログ取得を自動実行しません。

## スクリプトが確認すること

- OSがx64であること
- 利用者が配置したINF・CATのSHA256が、実機で検証したファイルと一致すること
- CATのAuthenticode署名がValidで、署名者がMicrosoft Windows Hardware Compatibility Publisherであること
- 確認に合格した場合だけ、Windows標準PnPUtilでインストールすること

実機確認時のINFはLOCOSYS 1.10.03.22（2010-03-22）、NTamd64、
対象ID USB\Vid_0e8d&Pid_3329で、Windows標準usbser.sysを使用する構成でした。
実機でSignToolのカーネルモード検証とCATに対するINFの整合性検証に合格しました。
このスクリプトでは固定ハッシュで同じファイルに限定し、
インストール時の署名・デバイス適合性の最終判定はWindowsに任せます。
Microsoft署名は、この非公式支援キットへの承認や全PCでの動作保証を意味しません。

| ファイル | SHA256 |
| --- | --- |
| Locosys_x64.inf | 145DDCDF2FF2DC2EDE7B7DDC86E35F09E1CFD6896BE8D71DF6CB6298AF18C116 |
| ls_gps_x64.cat | D17614AC70091DBB626F905B27289B1861CFD4833882E0561C1CA9088803B64E |

新しい版など、ハッシュの異なるファイルは停止します。検証を削除して強行しないでください。

## 失敗したとき

- ファイル不足: 上記の配置を確認する。
- ハッシュ・署名エラー: 配布元と取得ファイルを再確認する。署名検証を無効にしない。
- アクセス拒否: 管理者確認、または組織の管理者に確認する。
- 導入成功なのにCOMがない: 電源、データ通信対応USBケーブル、接続、ハードウェアIDを確認する。
- Windowsが再起動を求めた場合: 作業を保存して自分で再起動する。
- その他: C:\Windows\INF\setupapi.dev.log を確認する。公開相談時は個人情報を除く。

スクリプトは自動再起動、GPS設定変更、記録ログ消去を行いません。
署名強制、Secure Boot、メモリ整合性、実行ポリシーも変更しません。
